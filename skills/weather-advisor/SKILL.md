# 天气建议技能

## 步骤
1. 调用 getWeather 工具获取目标城市天气(city 参数传中文城市名,返回未来 7 天可读文本:日期、天气、气温范围、风力)
2. 找到目标日期对应的那一行,按以下规则组织建议:
   - 天气含"雨" → 提醒带伞;含"雪" → 提醒防滑保暖
   - 最高温 > 30℃ → 防暑建议;最低温 < 5℃ → 保暖建议
3. 建议必须引用工具返回的真实数据,禁止编造

## 输出格式
先一句结论,再给 2-3 条具体建议,不超过 100 字。
